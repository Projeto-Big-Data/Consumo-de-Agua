# Projeto Consumo Médio de Água 💧
O projeto tem como objetivo coletar, organizar e tratar dados sobre consumo de água em um condominio disponibilizados pela empresa Hydromet, utilizando python e a biblioteca pandas, com o proposito de organizar e preparar informações para analise e alimentar o painel grafico desenvolvido no Power BI.

# Tecnologias Utilizadas: 👾
* PYTHON
* PANDAS
* EXCEL
* POWER BI
* GITHUB

# Como funciona: 🤔
1. A planilha Consumo_medio.xlxs é tratada pelo script tratamento.py
2. Após ser tratada, o script exporta os novos dados tratados para uma planilha chamada consumo_medio_tratado.xlxs
3. Os gráficos do Power BI organizam os novos dados em gráficos interativos para maior facilidade de compreensão

# Tratamento de Dados: 📟
* Organização das colunas
* Separação de bloco e apartamento
* Cálculo da diferença entre consumo e média
* Cálculo do percentual de consumo
* Classificação dos apartamentos

# Objetivo final: 🥇
Facilitar o acompanhamento do consumo de água, permitindo identificar diferenças entre apartamentos e blocos.
